# VITALIS Feature Guide

VITALIS is a wellbeing website prototype for hydration, meals, movement, and healthy routines. The app includes a personalized dashboard; hydration tracking; a seven-day meal plan with recipes, prep timer, serving controls, and shopping list; workout suggestions and logging; profile setup; four age styles; settings; SDG 3 information; and the VITA in-app guide.

BMI, water, nutrition, energy, and calorie-burn values are estimates only and are not medical advice.
